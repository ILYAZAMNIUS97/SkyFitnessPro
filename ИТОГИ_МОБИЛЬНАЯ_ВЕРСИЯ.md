## 🚀 Как запустить и проверить

### 1. Запуск проекта:

```bash
npm install      # Если еще не установлены зависимости
npm run dev      # Запуск dev сервера
```

Откройте: `http://localhost:3000`

### 2. Тестирование в браузере:

**Chrome/Edge:**

1. Нажмите `F12` (открыть DevTools)
2. Нажмите `Ctrl+Shift+M` (режим устройства)
3. Выберите устройство: iPhone 12, iPad и т.д.

**Firefox:**

1. Нажмите `F12`
2. Нажмите `Ctrl+Shift+M` (адаптивный режим)

### 3. Ручное изменение размера:

- Просто меняйте ширину окна браузера
- Наблюдайте плавные переходы на breakpoints

## 🎯 Рекомендации

### Для дальнейшей разработки:

1. **Следуйте принципу Mobile-First:**

```css
/* 1. Базовые стили для мобильных */
.element { ... }

/* 2. Адаптация для планшетов */
@media (min-width: 768px) { ... }

/* 3. Адаптация для desktop */
@media (min-width: 1200px) { ... }
```

2. **Минимальные размеры для touch:**

- Кнопки: минимум 44x44px
- Ссылки: достаточный padding

3. **Тестируйте на реальных устройствах:**

- Эмулятор хорош, но реальные устройства лучше

## 🐛 Частые проблемы и решения

### Проблема: Изменения не видны

**Решение:** Hard refresh

```
Windows/Linux: Ctrl + Shift + R
Mac: Cmd + Shift + R
```

### Проблема: Горизонтальный скролл

**Решение:** Проверьте `overflow-x: hidden` в globals.css

### Проблема: Текст слишком мелкий

**Решение:** Проверьте viewport meta-тег в \_document.tsx

### Проблема: Изображения искажены

**Решение:** Убедитесь, что `object-fit: cover` применен
