## 🚀 Запуск за 3 шага

### 1️⃣ Создайте файл `.env.local`

Создайте файл `.env.local` в корне проекта:

```env
MONGODB_URI=mongodb://localhost:27017/skyfitnesspro
JWT_SECRET=your-secret-key-here
NEXT_PUBLIC_API_URL=http://localhost:3000
```

### 2️⃣ Установите зависимости (уже сделано)

```bash
npm install
```

### 3️⃣ Запустите приложение

```bash
# Сначала заполните БД тестовыми данными (5 курсов)
npm run seed

# Затем запустите сервер разработки
npm run dev
```

Откройте: **http://localhost:3000**

## 📋 Важные заметки

### MongoDB

Приложение требует подключения к MongoDB. Выберите один из вариантов:

**Локальная MongoDB:**

- Установите MongoDB Community Server
- Запустите MongoDB на порту 27017
- Используйте строку: `mongodb://localhost:27017/skyfitnesspro`

**MongoDB Atlas (облачная):**

1. Создайте бесплатный аккаунт на mongodb.com/cloud/atlas
2. Создайте кластер
3. Получите строку подключения
4. Замените значение `MONGODB_URI` в `.env.local`

### Тестовые данные

После запуска `npm run seed` в БД будут добавлены:

- 5 курсов с разными уровнями сложности
- Изображения используются из папки `/img`

## ❓ Проблемы?

**MongoDB не подключается?**

- Проверьте, что MongoDB запущен
- Проверьте строку подключения в `.env.local`
- Проверьте порт 27017

**Приложение не запускается?**

- Удалите `node_modules` и `package-lock.json`
- Выполните `npm install` заново
- Убедитесь, что Node.js версии 18+

**Нет курсов на главной?**

- Запустите `npm run seed` для добавления тестовых данных
- Проверьте подключение к MongoDB
- Проверьте консоль на наличие ошибок
