# SkyFitnessPro — Итоговая презентация проекта

---

## 📋 Общая информация

**SkyFitnessPro** — современное веб-приложение для занятий фитнесом в домашних условиях. Приложение позволяет пользователям выбирать курсы тренировок, следить за прогрессом выполнения упражнений и просматривать обучающие видеоматериалы.

### Целевая аудитория

- Люди, желающие заниматься спортом дома
- Пользователи без опыта тренировок (начинающие)
- Пользователи с базовым опытом, желающие структурировать тренировки

1. **DRY (Don't Repeat Yourself)**

   - Общие компоненты для карточек курсов

2. **KISS (Keep It Simple, Stupid)**
   - Простые и понятные функции
   - Чёткое разделение ответственности
   - Минимум зависимостей между модулями

3. **Модульность**
   - Независимые компоненты

4. **Документация**
   - JSDoc комментарии для всех функций
   - Описание параметров и возвращаемых значений
   - Примеры использования в комментариях

## 🔐 Безопасность

### Аутентификация

**JWT (JSON Web Tokens)**

- Токены с временем жизни 7 дней
- Подпись токена секретным ключом (JWT_SECRET)
- Хранение токена в localStorage клиента
- Проверка токена на каждом защищённом запросе

**Хеширование паролей**

- Алгоритм bcrypt с 10 раундами соли
- Пароли никогда не хранятся в открытом виде
- Невозможность восстановления исходного пароля

### Защита данных

**Валидация на клиенте**

- Zod схемы для проверки входных данных
- Проверка формата email
- Минимальная длина пароля (6 символов)
- Проверка совпадения паролей при регистрации

**Валидация на сервере**

- Проверка наличия обязательных полей
- Нормализация email (lowercase, trim)
- Проверка существования пользователя
- Корректные HTTP статус коды для ошибок

**Защищённые API роуты**

- Middleware `requireAuth()` для проверки токена
- Автоматический ответ 401 при невалидном токене
- Логирование ошибок аутентификации

### Обработка ошибок

- Централизованные сообщения об ошибках (`API_MESSAGES`)
- Безопасные сообщения (не раскрывают внутреннюю структуру)
- Graceful degradation при недоступности сервисов
