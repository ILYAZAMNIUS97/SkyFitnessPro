## 🔍 Технические детали

### Почему Next.js не разрешает viewport в \_document.tsx?

Next.js 13+ имеет специальную обработку viewport meta-тега для оптимизации. Viewport тег должен быть на уровне страницы, а не в глобальном `_document.tsx`.

### Альтернативный способ (Next.js 13+ App Router):

Если используете App Router:

```tsx
// app/layout.tsx
export const metadata = {
  viewport: 'width=device-width, initial-scale=1.0, maximum-scale=5.0',
};
```

Но мы используем Pages Router, поэтому добавляем viewport на каждую страницу.
