## 🚀 Запуск

```bash
# 1. Установите зависимости (если еще не установлены)
npm install

# 2. Запустите dev сервер
npm run dev

# 3. Откройте браузер
# http://localhost:3000
```

---

## 📱 Как протестировать

### Способ 1: Chrome DevTools (Рекомендуется)

1. Откройте `http://localhost:3000`
2. Нажмите `F12` (открыть DevTools)
3. Нажмите `Ctrl+Shift+M` (режим устройства)
4. Выберите устройство:
   - **iPhone 12** (390x844)
   - **iPhone SE** (375x667)
   - **iPad** (768x1024)

### Способ 2: Изменение размера окна

1. Откройте `http://localhost:3000`
2. Уменьшайте ширину окна браузера
3. Наблюдайте изменения на breakpoints:
   - `1200px` - Laptop
   - `768px` - Tablet
   - `480px` - Mobile
   - `360px` - Small Mobile

## 🐛 Частые проблемы

### Проблема: Не видно изменений

**Решение:** Hard refresh - `Ctrl+Shift+R` (Windows) или `Cmd+Shift+R` (Mac)

### Проблема: Горизонтальный скролл

**Решение:** Проверьте, что `overflow-x: hidden` в `globals.css`

### Проблема: Изображения искажены

**Решение:** `object-fit: cover` должен быть применен ко всем изображениям
