# 🏃 Инструкция: Добавление изображения бегуна

## ✅ Код уже готов! Осталось добавить файл.

### Шаг 1: Сохраните изображение

1. Щелкните правой кнопкой мыши на изображение бегуна (которое вы прикрепили в чат)
2. Выберите "Сохранить изображение как..."
3. Назовите файл **`runner.png`**
4. Сохраните на рабочий стол или в Downloads

### Шаг 2: Скопируйте файл в проект

Скопируйте файл `runner.png` в папку:

```
C:\SkyFitnessPro\public\img\runner.png
```

### Шаг 3: Проверка

1. Откройте папку `C:\SkyFitnessPro\public\img\` в проводнике
2. Убедитесь, что файл `runner.png` там находится
3. Обновите страницу в браузере (Ctrl + F5)
4. Откройте http://localhost:3000/course/[id-йоги]
5. Прокрутите вниз до секции "Начните путь к новому телу"
6. ✨ Изображение бегуна должно отображаться!

---

## 🎨 Что будет отображаться:

- Изображение бегуна в стартовой позиции
- Анимированные декоративные круги на фоне (зеленые с эффектом пульсации)
- Адаптивное масштабирование под разные экраны

---

## Альтернативный способ (через PowerShell):

Если файл находится на рабочем столе:

```powershell
copy "$env:USERPROFILE\Desktop\runner.png" "public\img\runner.png"
```

Если в Downloads:

```powershell
copy "$env:USERPROFILE\Downloads\runner.png" "public\img\runner.png"
```

---

## ⚠️ Важно:

- Имя файла должно быть **точно** `runner.png` (маленькими буквами)
- Формат: PNG
- Расположение: `public/img/runner.png`

После добавления файла - просто обновите страницу в браузере!
