# 🏃 Инструкция: Добавление изображения бегуна

## Быстрое решение:

### Способ 1: Ручное добавление (РЕКОМЕНДУЕТСЯ)

1. **Сохраните изображение бегуна**, которое вы прикрепили в чат
2. **Переименуйте** его в `runner.png`
3. **Скопируйте** файл в папку `C:\SkyFitnessPro\public\img\runner.png`

### Способ 2: Через командную строку

Если изображение находится на рабочем столе:

```bash
copy "%USERPROFILE%\Desktop\runner.png" "public\img\runner.png"
```

### Способ 3: Скачать из интернета

Используйте изображение спортсмена в стартовой позиции, похожее на то, что в макете Figma.

---

## Требования к изображению:

- **Формат:** PNG (с прозрачным фоном - желательно)
- **Размер:** Рекомендуется 500-800px по ширине
- **Название:** `runner.png`
- **Путь:** `public/img/runner.png`

---

## Проверка:

После добавления изображения:

1. Обновите страницу в браузере (Ctrl + F5)
2. Откройте страницу курса: http://localhost:3000/course/[id]
3. Прокрутите вниз до секции "Начните путь к новому телу"
4. Изображение должно отображаться справа

---

## Если изображение все еще не отображается:

### Проверьте консоль браузера:

1. Нажмите F12
2. Перейдите на вкладку "Console"
3. Ищите ошибки загрузки изображения

### Проверьте путь к файлу:

```
C:\SkyFitnessPro\public\img\runner.png
```

Файл должен физически существовать по этому пути.

---

## Альтернатива: Использовать другое изображение

Если у вас нет нужного изображения, можете:

1. Найти похожее изображение спортсмена
2. Использовать любое изображение из `public/img/` (например, `3.jpg`)
3. Временно оставить декоративные круги без изображения

Для временной замены измените в коде:

```typescript
<img src="/img/3.jpg" alt="Start your fitness journey" />
```

Сейчас код настроен с красивыми анимированными декоративными кругами на фоне,
так что даже если изображение не загрузится, секция будет выглядеть стильно!
