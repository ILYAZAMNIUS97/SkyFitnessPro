## 🎯 Что исправлено

### ❌ Убран зеленый блок "Измени своё тело за полгода!" на мобильных

**Проблема:**  
Зеленый блок с текстом "Измени своё тело за полгода!" отображался на мобильных устройствах, но в макете его **НЕТ**!

**Решение:**  
Добавлен `display: none` для `.heroCallout` на всех мобильных breakpoints (< 768px).

**Обновленный файл:**

- ✅ `styles/Home.module.css` - зеленый блок скрыт на мобильных

## 🔍 Технические детали

### Изменения в `styles/Home.module.css`:

**Было:**

```css
@media (max-width: 768px) {
  .heroCallout {
    width: 100%;
    max-width: 100%;
    height: auto;
    padding: 14px 18px;
    font-size: 24px;
    border-radius: 8px;
  }

  .heroCallout::after {
    display: none;
  }
}
```

**Стало:**

```css
@media (max-width: 768px) {
  .heroCallout {
    display: none; /* ← Полностью скрыт на мобильных */
  }
}
```
