## 📝 Шаги для запуска:

### Шаг 1: Создайте файл `.env.local`

Создайте файл `.env.local` в корне проекта (рядом с `package.json`) со следующим содержимым:

```env
# MongoDB Connection String
# Вариант 1: Локальная база данных MongoDB
MONGODB_URI=mongodb://localhost:27017/skyfitnesspro

# Вариант 2: MongoDB Atlas (облачная БД)
# MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/skyfitnesspro?retryWrites=true&w=majority

# JWT Secret для аутентификации
JWT_SECRET=your-super-secret-jwt-key-change-in-production

# Next.js API URL
NEXT_PUBLIC_API_URL=http://localhost:3000
```

**Важно:** Выберите один из вариантов подключения к MongoDB:

- **Локальная БД**: Убедитесь, что MongoDB запущен на вашем компьютере
- **MongoDB Atlas**: Зарегистрируйтесь на [mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas) и создайте бесплатный кластер

## ⚠️ Возможные проблемы

### Ошибка подключения к MongoDB

**Проблема:** `MongoServerError: connect ECONNREFUSED`

**Решение:**

1. Проверьте, запущен ли MongoDB локально:

   ```bash
   # Windows
   net start MongoDB

   # macOS/Linux
   sudo systemctl start mongodb
   ```

2. Или используйте MongoDB Atlas (облачную БД)

### Порт 3000 занят

**Проблема:** `Port 3000 is already in use`

**Решение:**

```bash
# Укажите другой порт
PORT=3001 npm run dev
```
