# 🚀 НАЧНИТЕ ЗДЕСЬ!

## ⚠️ ВАЖНО! Перед запуском

Создайте файл `.env.local` в **корне проекта** (рядом с package.json):

### Скопируйте и вставьте это содержимое:

```env
MONGODB_URI=mongodb://localhost:27017/skyfitnesspro
JWT_SECRET=your-secret-key-here-change-in-production
NEXT_PUBLIC_API_URL=http://localhost:3000
```

## 🎯 Быстрый запуск

После создания `.env.local`:

```bash
# 1. Заполните базу данных тестовыми данными
npm run seed

# 2. Запустите приложение
npm run dev

# 3. Откройте браузер
# http://localhost:3000
```

## 📋 Требования

✅ Node.js 18+ (уже установлен)  
✅ Зависимости (уже установлены: `npm install` выполнен)  
⚠️ MongoDB - **НУЖНО УСТАНОВИТЬ/НАСТРОИТЬ**

## 🗄️ Настройка MongoDB

### Вариант 1: Локальная MongoDB (рекомендуется для разработки)

1. Скачайте: https://www.mongodb.com/try/download/community
2. Установите MongoDB Community Server
3. Запустите MongoDB
4. Используйте строку подключения:
   ```
   MONGODB_URI=mongodb://localhost:27017/skyfitnesspro
   ```

### Вариант 2: MongoDB Atlas (облачная БД, бесплатно)

1. Зарегистрируйтесь: https://www.mongodb.com/cloud/atlas/register
2. Создайте бесплатный кластер (M0)
3. Создайте пользователя БД
4. Получите строку подключения
5. Замените в `.env.local`:
   ```
   MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/skyfitnesspro
   ```

## ❓ Проблемы?

### "Cannot connect to MongoDB"

→ Убедитесь, что MongoDB запущен или используйте MongoDB Atlas

### "Module not found"

→ Выполните `npm install`

### Нет курсов на странице

→ Запустите `npm run seed`

### Порт 3000 занят

→ Используйте `npm run dev -- -p 3001`
