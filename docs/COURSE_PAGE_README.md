# 📚 Страница курса - Документация

## ✅ Что реализовано

### 1. Новая страница курса согласно дизайну Figma

Страница курса полностью переработана и соответствует макету:

#### Структура страницы:

1. **Hero-баннер** (желтый фон)
   - Название курса слева
   - Изображение справа
   - Цвет фона настраивается для каждого курса (`backgroundColor`)

2. **Секция "Подойдет для вас, если:"**
   - 3 карточки с темным фоном
   - Нумерация зеленым цветом (#BCEC30)
   - Текстовое описание для каждой карточки

3. **Секция "Направления"**
   - Зеленый фон (#BCEC30)
   - Сетка из направлений курса (3 колонки)
   - Иконка "+" перед каждым направлением

4. **Секция "Начните путь к новому телу"**
   - Светло-серый фон (#F5F5F5)
   - Список преимуществ курса
   - Кнопка действия (добавить курс / войти)
   - Декоративное изображение справа

### 2. Функционал авторизации

#### Для неавторизованных пользователей:

- Кнопка: **"Войдите, чтобы добавить курс"**
- При клике открывается модальное окно авторизации
- После успешного входа пользователь может добавить курс

#### Для авторизованных пользователей:

- Если курс не добавлен: кнопка **"Добавить курс"**
- Если курс уже добавлен: кнопка **"Перейти к тренировкам"**
- После добавления курса - переход в профиль

### 3. API для управления курсами

**Endpoint:** `/api/user/courses`

#### GET - Получение списка курсов пользователя

```bash
GET /api/user/courses
Headers: Authorization: Bearer <token>
```

**Ответ:**

```json
{
  "courses": ["courseId1", "courseId2"]
}
```

#### POST - Добавление курса пользователю

```bash
POST /api/user/courses
Headers:
  Authorization: Bearer <token>
  Content-Type: application/json
Body:
{
  "courseId": "65..."
}
```

**Ответ:**

```json
{
  "message": "Курс успешно добавлен",
  "courses": ["courseId1", "courseId2", "newCourseId"]
}
```

#### DELETE - Удаление курса у пользователя

```bash
DELETE /api/user/courses
Headers:
  Authorization: Bearer <token>
  Content-Type: application/json
Body:
{
  "courseId": "65..."
}
```

## 🚀 Как использовать

### 1. Запуск проекта

```bash
# Установка зависимостей (если еще не установлены)
npm install

# Обновление базы данных
npm run seed

# Запуск сервера разработки
npm run dev
```

### 2. Тестирование страницы курса

1. Откройте главную страницу: http://localhost:3000
2. Кликните на карточку курса "Йога"
3. Вы попадете на страницу курса: http://localhost:3000/course/[courseId]

### 3. Тестирование функционала

#### Сценарий 1: Неавторизованный пользователь

1. Откройте страницу курса без авторизации
2. Увидите кнопку "Войдите, чтобы добавить курс"
3. Кликните на кнопку
4. Откроется модальное окно авторизации
5. Войдите или зарегистрируйтесь
6. После входа кнопка изменится на "Добавить курс"

#### Сценарий 2: Авторизованный пользователь (курс не добавлен)

1. Войдите в систему
2. Откройте страницу курса
3. Увидите кнопку "Добавить курс"
4. Кликните на кнопку
5. Курс будет добавлен, произойдет переход в профиль

#### Сценарий 3: Авторизованный пользователь (курс уже добавлен)

1. Откройте страницу курса, который уже добавлен
2. Увидите кнопку "Перейти к тренировкам"
3. Кликните на кнопку - переход в профиль

## 💡 Советы по разработке

### Как добавить новый курс:

1. Обновите `scripts/seed.ts`:

```typescript
{
  nameRU: 'Название курса',
  nameEN: 'Course Name',
  description: 'Список преимуществ через \\n',
  image: '/img/6.jpg',
  directions: ['Направление 1', 'Направление 2'],
  fitting: ['Подходит для 1', 'Подходит для 2'],
  difficulty: 'Начальный',
  durationInDays: 30,
  dailyDurationInMinutes: { from: 15, to: 45 },
  backgroundColor: '#FF5733',
  workouts: [],
}
```

2. Запустите seed:

```bash
npm run seed
```

### Как изменить стили курса:

Все стили находятся в `styles/CoursePage.module.css`. Основные классы:

- `.hero` - баннер курса
- `.fittingCard` - карточки "Подойдет для вас"
- `.directionsGrid` - секция направлений
- `.ctaSection` - секция с кнопкой действия
