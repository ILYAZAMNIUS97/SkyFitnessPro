# 🎉 ЭТАП 1 ЗАВЕРШЕН: Главная страница с курсами

## ✅ Реализовано

Я создал полноценное Next.js приложение для **SkyFitnessPro** - фитнес-приложения для домашних тренировок.

### Что работает:

#### 📱 **Страницы:**

1. **Главная (/)** - отображает все курсы из базы данных
2. **Страница курса (/course/[id])** - детальная информация о курсе
3. **Профиль (/profile)** - заглушка для будущей реализации

#### 🎨 **Компоненты:**

- **Layout** - общий макет с хедером
- **Header** - шапка с логотипом и навигацией
- **CourseCard** - красивая карточка курса с hover эффектами
- **ScrollToTop** - кнопка "Наверх" с плавной прокруткой (появляется при скролле вниз)

#### 🔌 **API:**

- `GET /api/courses` - получение всех курсов
- `POST /api/courses` - создание курса
- `GET /api/courses/[id]` - получение курса по ID
- `PUT /api/courses/[id]` - обновление курса
- `DELETE /api/courses/[id]` - удаление курса

#### 🗄️ **База данных:**

- Подключение к MongoDB через Mongoose
- 3 модели: Course, Workout, User
- Скрипт для заполнения тестовыми данными

#### 🎨 **Дизайн:**

- Современная фиолетовая цветовая схема (#580ea2)
- Адаптивный дизайн (desktop + mobile)
- Плавные анимации и переходы
- Градиенты и красивые тени
- Шрифт Inter от Google Fonts

## 🚀 Как запустить

### ⚠️ ВАЖНО! Сначала создайте `.env.local`

Создайте файл `.env.local` в корне проекта:

```env
MONGODB_URI=mongodb://localhost:27017/skyfitnesspro
JWT_SECRET=your-secret-key-here
NEXT_PUBLIC_API_URL=http://localhost:3000
```

### Затем выполните:

```bash
# 1. Заполнить БД тестовыми данными (5 курсов)
npm run seed

# 2. Запустить приложение
npm run dev

# 3. Открыть браузер
# http://localhost:3000
```
