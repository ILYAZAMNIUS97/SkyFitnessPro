# 🚀 Инструкция по установке и запуску SkyFitnessPro

## Шаг 1: Установка зависимостей

Откройте терминал в корневой папке проекта и выполните:

```bash
npm install
```

## Шаг 2: Настройка переменных окружения

Создайте файл `.env.local` в корне проекта со следующим содержимым:

```env
# MongoDB Connection String
MONGODB_URI=mongodb://localhost:27017/skyfitnesspro

# JWT Secret (используйте длинную случайную строку в продакшене)
JWT_SECRET=your-secret-key-here-change-in-production

# Next.js
NEXT_PUBLIC_API_URL=http://localhost:3000
```

### Варианты подключения MongoDB:

**Вариант 1: Локальная MongoDB**

- Установите MongoDB на свой компьютер
- Используйте строку подключения: `mongodb://localhost:27017/skyfitnesspro`

**Вариант 2: MongoDB Atlas (облачная БД)**

1. Зарегистрируйтесь на https://www.mongodb.com/cloud/atlas
2. Создайте бесплатный кластер
3. Получите строку подключения
4. Замените `MONGODB_URI` на полученную строку подключения

## Шаг 3: Заполнение базы данных тестовыми данными

После настройки подключения к MongoDB выполните:

```bash
npm run seed
```

Это добавит 5 тестовых курсов в базу данных.

## Шаг 4: Запуск приложения

Запустите проект в режиме разработки:

```bash
npm run dev
```

Откройте браузер и перейдите по адресу: **http://localhost:3000**

## ✅ Готово!

Теперь вы должны увидеть главную страницу с курсами тренировок.

## 🛠 Полезные команды

- `npm run dev` - запуск в режиме разработки
- `npm run build` - сборка для продакшена
- `npm run start` - запуск продакшен версии
- `npm run lint` - проверка кода линтером
- `npm run format` - форматирование кода
- `npm run seed` - заполнение БД тестовыми данными

## ❓ Решение проблем

### MongoDB не подключается

- Убедитесь, что MongoDB запущен (если используете локальную версию)
- Проверьте правильность строки подключения в `.env.local`
- Проверьте, что порт 27017 не занят другим приложением

### Приложение не запускается

- Удалите папку `node_modules` и файл `package-lock.json`
- Выполните `npm install` заново
- Убедитесь, что используете Node.js версии 18 или выше

### Страницы не отображаются

- Проверьте консоль браузера на наличие ошибок
- Убедитесь, что файл `.env.local` создан и содержит все необходимые переменные
- Перезапустите сервер разработки
