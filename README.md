# SkyFitnessPro

Современное фитнес-приложение для домашних тренировок на базе Next.js с TypeScript.

## 🎯 Основной функционал

- ✅ Просмотр курсов тренировок
- ✅ Личный кабинет пользователя
- ✅ Отслеживание прогресса тренировок
- ✅ Просмотр видеозаписей упражнений
- ✅ Управление курсами и тренировками
- ✅ Система аутентификации (JWT)
- ✅ **Полностью адаптивный дизайн** (320px - 4K+)

## 🛠 Технологический стек

- **Next.js 14** - React фреймворк
- **TypeScript** - типизация
- **MongoDB + Mongoose** - база данных
- **JWT** - аутентификация
- **SWR** - управление состоянием сервера
- **React Hook Form + Zod** - управление формами и валидация

## 🚀 Быстрый старт

### Предварительные требования

- Node.js 18.x или выше
- MongoDB (рекомендуется использовать Docker контейнер - см. раздел ниже)

### Установка

1. Клонируйте репозиторий

```bash
git clone <repository-url>
cd SkyFitnessPro
```

2. Установите зависимости

```bash
npm install
```

3. Создайте файл `.env.local` в корне проекта:

```env
MONGODB_URI=mongodb://localhost:27017/skyfitnesspro
JWT_SECRET=your-secret-key-here-change-in-production
NEXT_PUBLIC_API_URL=http://localhost:3000
```

4. Запустите MongoDB (рекомендуется использовать Docker - см. раздел ниже)

5. Заполните базу данных тестовыми данными (опционально)

```bash
npm run seed
```

6. Запустите проект в режиме разработки

```bash
npm run dev
```

7. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## 🔧 Конфигурация

### MongoDB

Для работы приложения требуется подключение к MongoDB. Рекомендуемые способы:

#### 🐳 Использование Docker (рекомендуется)

Самый простой способ для локальной разработки - использовать Docker контейнер:

1. Убедитесь, что у вас установлен [Docker](https://www.docker.com/get-started)

2. Запустите MongoDB контейнер:

```bash
docker run -d \
  --name mongodb \
  -p 27017:27017 \
  -e MONGO_INITDB_DATABASE=skyfitnesspro \
  mongo:latest
```

3. Контейнер будет работать в фоновом режиме. Для остановки:

```bash
docker stop mongodb
```

4. Для повторного запуска существующего контейнера:

```bash
docker start mongodb
```

5. Для удаления контейнера (если нужно):

```bash
docker rm mongodb
```

**Преимущества Docker:**

- ✅ Не требует установки MongoDB на систему
- ✅ Легко запустить/остановить
- ✅ Изолированная среда
- ✅ Простое управление версиями

#### Альтернативные способы:

- **Локальная установка MongoDB** - установите MongoDB Community Edition с [официального сайта](https://www.mongodb.com/try/download/community)
- **MongoDB Atlas** - облачная база данных (бесплатный tier доступен)

Строка подключения указывается в файле `.env.local`:

- Для Docker/локальной установки: `mongodb://localhost:27017/skyfitnesspro`
- Для MongoDB Atlas: используйте строку подключения из панели управления Atlas

### Переменные окружения

Создайте файл `.env.local` со следующими переменными:

```env
MONGODB_URI=         # Строка подключения к MongoDB
JWT_SECRET=          # Секретный ключ для JWT токенов
NEXT_PUBLIC_API_URL= # URL вашего API (http://localhost:3000 для разработки)
```
